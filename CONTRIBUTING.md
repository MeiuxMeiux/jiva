# Contributing

Small, focused changes are welcome. JIVA is alpha; open an issue first for anything large.

## Setup

Linux or WSL2. bash ≥4, git, tmux ≥3.2, jq ≥1.6, just, python3, util-linux (flock, setsid), coreutils, Claude Code. Optional: gh, shellcheck, gitleaks.
macOS: untested (needs Homebrew bash, coreutils, util-linux).

gitleaks is optional to run JIVA, but the pre-commit hook installed by `just init` refuses to commit
without it. Set up permissions as in [docs/QUICKSTART.md §0](docs/QUICKSTART.md).

```
git clone https://github.com/MeiuxMeiux/jiva ~/jiva
cd ~/jiva && just init        # hooks path (gitleaks pre-commit), skeleton dirs
export PATH="$HOME/jiva/bin:$PATH"
```

`bin/jiva` is a symlink to `core/jiva.sh`: edit `core/jiva.sh`, never `bin/jiva`.

## Before you open a PR

- `just check` is green: files ≤150 lines, notes ≤30, scripts parse, JSON valid, shellcheck,
  README/QUICKSTART drift vs `jiva help` + `just --list`.
- `just doctor` is green (needs tmux; run it on your machine, CI does not).
- Site changes: `just site-check` is green too.
- New verb or recipe: README's verbs table is generated by `scripts/readme-drift.py --table`.

## House rules

- Every file ≤150 lines; `notes/*.md` ≤30 lines. Split rather than grow.
- Prefer a `just` recipe over ad-hoc shell; if you repeat a sequence twice, propose a recipe.
- No secrets in git, logs or the board. Keys are read only inside scripts, via `scripts/keys.sh`.
- No copyrighted art in git. Private test rosters go in `packs/local/` (gitignored); shipped packs
  follow [packs/README.md](packs/README.md).
- The dashboard binds to `127.0.0.1` only; keep it that way.

## Commits

Small and conventional-ish, prefixed with the area, matching the log:
`core: …`, `dash: …`, `site: …`, `plugin: …`, `docs: …`, `notes: …`. One concern per commit.
No DCO or sign-off is required.
