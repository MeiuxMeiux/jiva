# core — durable facts (spike re-green 2026-10-13, claude 2.1.296, tmux 3.4; `jiva spike` per update)

- Split out: permissions/trust/auto-mode/asks → notes/perms.md; breakers/flags/parked/guard → notes/breakers.md.
- Affinity: hooks/affinity.sh → .jiva/affinity.tsv (ts, soul, depth-2 dir; ≤2000 rows). `jiva pick`: Σ0.5^age_days, idle unparked wN.
- Native messaging: SendMessage between tmux sessions, UDS `/run/user/$UID/cc-socks/<pid>.sock`; an idle peer wakes on an inbound message. ListAgents shows peer name + tmux pane id.
- `claude agents --json`: `{pid,cwd,kind,sessionId,name,status}`; status idle|busy|waiting;
  stuck at a prompt → `"status":"waiting","waitingFor":"permission prompt"`.
- Status line JSON has `context_window.{used_percentage,total_input_tokens,context_window_size}`,
  `exceeds_200k_tokens`, `cost.total_cost_usd`, `rate_limits.{five_hour,seven_day}.used_percentage`. Window 1M, so the ~200k ceiling is JIVA policy, not native.
- SessionStart hook `additionalContext` reliably delivers the handoff; `respawn-pane -k` gives a fresh
  session id with no trust re-prompt.
- WSL 2.6 + systemd, no keepalive in `.wslconfig`: distro idle-stops when no Windows client is attached.
- Portability (core/lib.sh): JIVA_HOME = this checkout, TARGET = $JIVA_TARGET or git toplevel of $PWD;
  state in $TARGET/.jiva, socket `jiva` for JIVA_HOME else `jiva-<basename>`. Panes: --settings $J/settings.json (hooks dropped if plugin installed, notes/plugin.md).
- Recipes from `jiva mine`: `just review <sha>` (stat+check+non-ok doctor), `just card <w> <f>` (≤20 then assign),
  `just restart-watchdog` (= `jiva restart-watchdog`, respawn-pane on $SOCK), `just hive` (status + inbox 8),
  `just peek|tell|windows|unpark` (justfile runs bash; `. core/lib.sh` gives $J + T). Convention: a key ≥3× across
  lives in `just mine 15` (`all` for trivial) → one-line recipe; never one that pushes/deploys/touches ~/.claude.
- mine keys: ≤3 distinct statements " + ", echo/cd/sleep dropped, heredoc → cat>file; trivial hidden (`mine n all`).
- Parent-dir mode (PLAN, unbuilt): TARGET=parent, `.jiva/` there, claims `<repo>/<path>`, ship per repo.
- README/QUICKSTART drift: scripts/readme-drift.py in core/check.sh — names ⊆ help/recipes, README `<!-- verbs:begin/end -->` table regenerated by `--table`, `<!-- blurb -->` == hero.html `<p class="lede">`s.
- Never `rm -rf` a computed path (`$(mktemp -d)`, `$J`, `$tmp`) in an ad-hoc Bash command: it trips the native
  "Dangerous rm" prompt and pings the keeper. Scratch lives in a script with cleanup behind `trap`, or in a fixed
  literal path /tmp/jiva-scratch/<name> (`jiva scratch <name>` makes/cleans it). Ad-hoc `python3 - <<EOF` rewrites are fine.
