10Methodology

Every number on this page is a field of one public file, data.json (schema ). Check it yourself: each claim above can be recomputed from it.

What was counted

Claude Code session transcripts on machines, from to : usage numbers per request, model, hour, role and tool names. Never message text, tool inputs or outputs, file paths or prompts. The counting script spends zero model tokens.

Definitions

request
one API call
turn
from one prompt to the next
session
one transcript; a subagent session is one spawned by another session
cache hit
cache reads divided by all input tokens
context
input plus cache write plus cache read of one request
handoff start
a session that reads a handoff file within its first six tool calls
rotation window
a session that ends between 150k and 210k tokens of context
idle turn
a prompt answered with no tool call
re-warm
a request after a gap of more than 5 minutes that wrote more cache than it read

Anonymisation

Repos are lettered in order of first activity and repos with fewer than 5 sessions are pooled as misc. Machines are numbered. Nothing finer than the hour is published, and labels can shift between refreshes. Two separate scrubs, one where the data is made and one in this site's build, fail on anything that looks like a name, path, host, address or key.

Limits

  • About 30 days: older transcripts are pruned before they can be counted.
  • machines only; work sessions are excluded.
  • Edits done through the shell are not counted as edits.
  • Idle-turn detection cannot tell a useful one-line answer from a poll.
  • Plan quota, latency and the quality of the work are not measured.
  • Velocity counts every branch and treats a tag as a release.
