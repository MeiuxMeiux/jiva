09Crosstalk, across servers

Claude Code sessions can message each other on one machine. Crosstalk carries that across machines with nothing new to install: tmux, ssh and just.

  1. Each box gets five recipes: agents, peek, say, post, outbox. say types a stamped line into a session's pane and refuses if that pane sits at a permission prompt.
  2. Your hub gets one recipe per box. It runs the box's recipes over ssh, so just ernie say desk "ship it" reaches an agent on another server.
  3. The way back is a file. Far agents post to an append-only outbox, and the hub follows it with tail -F. That costs no tokens until a message lands.

Rules come from real incidents: never type into a prompt, clear the input box first, append and never rewrite, quote with printf %q, and write down who the desk is.

From your desk, to a box

$ just ernie agents             # busy | idle | PROMPT
$ just ernie peek gw-boss 20
$ just ernie say desk "status?"

From any agent there, back to you

$ just xt post "GW status" "3 shipped, 1 needs Jack"

JIVA Crosstalk: one file, no install

One markdown, pasted in as CROSSTALK.md. Your agent writes crosstalk.just on each box and the hub recipe, adds three lines to CLAUDE.md, and runs a two-minute test against a fake agent before a single token is spent.
