01The problem

Run four Claude Code sessions by hand and you get four terminal tabs, four permission prompts you can't see, and four contexts that slowly fill with stale tool output. Around 200k tokens a session starts forgetting its own plan. You notice later, when the work drifts.

JIVA turns that into a routine. Each session has a role, a task card of 20 lines or fewer, and a fixed exit: write a handoff of 40 lines or fewer, stop, get respawned. You watch one terminal and one status line instead of tabs.
